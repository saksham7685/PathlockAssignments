## Overview of Assignments

### **Assignment 1 – Basic Task Manager** (10 Credits)
**Objective:**  
Implement a simple full-stack task management app to demonstrate fundamental backend and frontend skills.

**Requirements:**
- **Backend:**  
  - Build a RESTful API using **.NET 8 Core**
  - Use **in-memory storage** (no database)
  - CRUD endpoints for task management

- **Frontend:**  
  - Built with **React + TypeScript**
  - Display, add, toggle, and delete tasks
  - Use Axios or Fetch for API calls
  - Manage state with React Hooks

**Enhancements (Optional):**
- Task filtering (All / Completed / Active)
- Basic design using Tailwind or Bootstrap
- Persist tasks with `localStorage`

---

### **Assignment 2 – Mini Project Manager** (20 Credits)
**Objective:**  
Develop a multi-user project management application with authentication, entity relationships, and modular architecture.

**Core Features:**
- **Authentication:**  
  - User registration & login using JWT  
  - Users can only access their own data

- **Projects:**  
  - Create, view, and delete projects  
  - Each project has a title, description, and creation date  

- **Tasks:**  
  - Each project contains multiple tasks  
  - Tasks have a title, due date, and completion status

**Tech Stack:**
- Backend: **C# (.NET 8 Core + EF Core)**
- Frontend: **React + TypeScript**
- Use **React Router** for navigation
- JWT-based authentication persistence

**Recommended Enhancements:**
- Loading indicators & form validation
- Responsive (mobile-friendly) design
- Deploy backend (Render) & frontend (Vercel)

### **Assignment 3 – Smart Scheduler API** (Linked to Mini Project Manager, +10 Credits)
## 🎯 Objective

The Smart Scheduler API is an enhancement to the **Mini Project Manager** app.  
It introduces an intelligent backend endpoint that automatically helps users plan and schedule their project tasks efficiently.

This assignment demonstrates the candidate’s ability to:
- Extend an existing full-stack application
- Design and expose a custom RESTful endpoint
- Work with JSON-based input/output
- Provide meaningful feedback and user experience improvements
